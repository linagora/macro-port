# Macro-Port

Open source analyzer of Excel VBA macros, built to prepare migrations from Microsoft Excel to OnlyOffice Spreadsheet, Grist and LibreOffice Calc.

Macro-Port inventories the macros of a whole file share or of a single workbook, tells what each procedure is used for (formatting, consolidation, lookups, forms, reporting, external data, Office automation, Windows API...), how complex and how risky it is, and produces JSON, HTML and CSV reports. Analysis runs entirely on your machine or in your browser: files never leave your organisation.

Status: Lot 1 (inventory) in development. See `docs/SPEC-LOT1.md`.
